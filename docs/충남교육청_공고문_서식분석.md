# 충청남도교육청 공고문 서식 분석

기준일: 2026-09-26

## 분석 기준 자료

### 1. 충청남도교육청 공고 제2026-30호

- 나라장터 공고번호: R26BK01346251
- 제목: 일반용역 입찰(제한경쟁, 총액) 공고
- 발주기관: 충청남도교육청
- 공식 나라장터 PDF를 기준으로 첫 장, 규정 안내장, 본문장을 비교했다.

관찰된 특징:

- A4 세로
- 첫 장 좌측 상단에 공고번호
- 매우 큰 중앙 제목
- 우측에 공고일과 회계관 직명
- 제목 아래 핵심 용역명·개찰일시를 비교적 굵고 크게 배치
- 긴 안내문은 가는 실선 사각박스 안에 배치
- 규정 안내는 큰 외곽박스 안에 글머리표와 별도 안쪽박스를 조합
- 청렴계약 안내는 중앙 제목을 박스 상단 경계에 걸친 형태로 강조
- 본문은 `1. 입찰에 부치는 사항` 같은 굵은 대항목과
  `가. 나. 다.` 세부항목 구조
- 중요 용어 일부는 굵게 또는 색상으로 강조
- 하단 중앙에 `- 1 -` 형태의 쪽번호

### 2. 충청남도교육청 공고 제2025-37호

기술용역 공고를 비교자료로 사용했다.

- 공고번호 → 중앙 제목 → 바로 본문으로 내려가는 간결형
- 본문 대항목은 굵고 크며, 본문은 명조계열의 긴 문장
- 페이지 하단 중앙 쪽번호
- 금액·날짜·전자계약 등 핵심어 강조

## 학교 소액수의 공고 적용

학교 실무에서는 본청 공고보다 핵심조건을 표로 먼저 보여주는 소액수의 공고가 많으므로
딸깍 물품·공사 공고문은 다음의 혼합형을 기본으로 한다.

1. 공고번호
2. 중앙 제목
3. 공고일·학교명
4. 입찰 유의사항 박스
5. 청렴계약 박스
6. 1번 대항목 아래 핵심정보 4열 표
7. 2번 이후 전자견적/참가자격/예정가격/계약상대자 결정/전자계약 조항
8. 마지막 공고문구·공고일·학교장
9. 중앙 쪽번호

이 구조는 충청남도교육청 본청 공고의 공공문서 조판과 학교 소액수의 공고의
실무 가독성을 함께 반영한다.

## 한컴오피스 실물 검증 항목

- 제목이 한 줄에 들어오는 최대 길이
- 휴먼명조/휴먼고딕 대체폰트 발생 여부
- 표 셀 높이와 자동 줄바꿈
- 긴 세부항목의 페이지 넘김
- 청렴계약 박스가 페이지 경계에서 잘리는지
- 쪽번호 위치
- 학교장 서명부의 페이지 고립 여부
- 인쇄/PDF 변환 시 테두리 두께

다운로드한 실제 HWPX 첫 페이지를 기준으로 0.5~1pt, 1~2mm 단위로 재조정한다.
