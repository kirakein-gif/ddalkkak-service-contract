# 통학차량·통학버스 용역 샘플 분석

- 조사 기준일: 2026-09-25
- 우선순위: 학교 직접 발주
- 목적: 통학차량 전용 Rule Engine과 공고/과업지시서 입력항목 정의

## 1. 핵심 결론

학교 통학차량은 다음 요소가 동시에 결합된 용역이다.

1. 지방계약 금액기준
2. 전세버스운송사업 업종자격
3. 중소기업자간 경쟁제품·직접생산확인
4. 차량·보험·차령
5. 학생 연령에 따른 어린이통학버스 규정
6. 운전원·동승보호자
7. 학교가 정하는 노선·운행일수·차량규격
8. 경쟁입찰 시 여객 육상운송용역 적격심사

따라서 **금액엔진 + 중소기업제품 엔진 + 차량안전 엔진**의 3층 구조로 설계한다.

## 2. 중소기업자간 경쟁제품 세부품명

2026-09-25 현재 SMPP 목록에서 확인:

- 통학운송서비스: 7811189902
- 기타도로여객운송서비스: 7811189904

학교 공고마다 사용하는 세부품명이 다르므로 프로그램이 하나를 고정하지 않는다.
사용자가 실제 과업에 맞는 세부품명을 선택하고, 공고 시점 SMPP 최신 목록을 재확인한다.

## 3. 직접생산확인

「중소기업제품 구매촉진 및 판로지원에 관한 법률」 제9조와
같은 법 시행령 제10조의 수의계약 직접생산 확인 금액기준은 **추정가격 1천만원**이다.

따라서 현재 Rule Engine은 알려진 경쟁제품 세부품명을 선택하고
추정가격이 1천만원 이상이면 직접생산확인증명서를 준비·확인 서류에 자동 추가한다.

실제 2026년 학교 통학버스 특수조건에서도
통학운송서비스(7811189902) 직접생산확인증명서를 요구하는 사례가 확인된다.

## 4. 대표 학교 계약에서 확인된 흐름

### 1억원 이하

충남 서부초 통학차량처럼 수천만원대에서는
2인 이상 견적·88%·복수예가·업종/지역제한 구조가 확인된다.

의미:
- 기존 학교 일반용역 소액수의 Rule Engine을 활용
- 통학차량 업종·세부품명·직접생산·안전요건을 추가

다만 소액수의는 '가능'한 처리경로다.
발주기관이 경쟁입찰을 선택하는 경우도 있으므로 프로그램은 이를 의무경로로 표시하지 않는다.

### 경쟁입찰·적격심사

학교 통학차량 경쟁입찰에서는
조달청 일반용역 적격심사 세부기준의 여객 육상운송용역 기준이 적용되는 사례가 반복된다.

2026-07-27 중요한 개정:
- 개정 전 중소기업자간 경쟁 여객육상운송용역: 87.995%
- 2026-07-27 이후 최초 입찰공고분: **89.995%**
- 적격심사 통과점수: 88점

따라서 2026년 상반기 87.995% 학교 공고는 업무구조 연구용 샘플일 뿐,
현행 공고의 숫자로 복사하지 않는다.

## 5. 어린이통학버스

2026-07-01 시행 도로교통법상 어린이는 13세 미만이다.

유치원·초등학교 등 법이 열거한 시설에서 어린이 통학에 사용하는 차량은
어린이통학버스 신고·운영요건을 검토한다.

주요 자동 체크:
- 관할 경찰서 신고
- 신고증명서
- 구조·도색·표지·안전장치
- 운전자 안전조치
- 성년 보호자 동승
- 운영자·운전자·동승보호자 안전교육
- 하차확인장치

현장체험학습 등 비상시적인 교육활동 이동은
도로교통법상 어린이통학버스 정의에서 제외되는 문구가 있으므로
'통학차량'과 '현장체험 차량'을 같은 템플릿으로 처리하지 않는다.

중학교·고등학교는 학교급만으로 어린이통학버스 규정을 자동 적용하지 않는다.
특수학교·혼합노선은 실제 13세 미만 학생 운송 여부를 추가 확인한다.

- 추정가격
- 총액/단가
- 운행일수

### 중소기업제품
- 통학운송서비스(7811189902)
- 기타도로여객운송서비스(7811189904)

### 운송대상

- 공동수급

## 8. 개발 안전원칙

- 법정 요건과 학교 선택 특수조건을 분리한다.
- 세부품명이 미정이면 89.995%를 자동 확정하지 않는다.
- 과거 공고의 낙찰하한율을 현재 계약에 복사하지 않는다.
- 공고일 기준 조달청 기준과 SMPP 목록을 다시 확인한다.
