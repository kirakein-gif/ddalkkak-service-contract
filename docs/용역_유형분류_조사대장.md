# 용역 유형분류·문구 조사대장

기준일: 2026-09-26  
목적: 충남교육청 계열 학교 계약문서를 여러 건 비교해, 자동생성기에 넣을 문장을 **법령상 공통 필수문구 / 충남 계열 반복문구 / 개별 특수조건**으로 분리한다.

이 문서는 단일 공고문을 템플릿으로 복제하기 위한 자료가 아니다. 공고일 현재 유효한 기준을 확인하고, 확인하지 못한 사항은 자동확정하지 않는다는 원칙을 기록한다.

## 1. 현재 서비스 분류

| 최상위 | 세부유형 | 문서 경로 | 우선 판정 |
|---|---|---|---|
| 용역 | 통학차량·통학버스 | `transport` | 전세버스 등록·어린이통학버스·SMPP·차량안전 |
| 용역 | 수학여행·현장체험학습 | `travel` | 제안서 필요성·여행업·숙박·식사·운송·인원정산 |
| 용역 | 방과후·늘봄 | `program` | 제안서·강사·프로그램·학생수/차시 정산 |
| 용역 | 시설 유지관리 | `facility` | 일반 유지관리와 기술용역 분리·면허·기술인력 |
| 용역 | 법정점검 | `facility` | 시설별 개별법령·점검주기·보고기한 |
| 용역 | 청소 | `labor` | 단순노무 원가·최저임금·4대보험·인력배치 |
| 용역 | 방역·소독 | `labor` | 소독업 등 자격·약품·학생동선 안전 |
| 용역 | 기타 학교 일반용역 | `general` | 과업별 면허·중소기업제품·안전·개인정보 |

통학차량은 용역의 세부유형이며, 공사·물품과 같은 최상위 분류로 두지 않는다.

## 2. 문구 분류 원칙

| 구분 | 프로그램 처리 | 예시 |
|---|---|---|
| A. 법령·예규상 공통 | 자동삽입하되 공고일 기준 버전 표기 | 전자입찰, 입찰무효, 예정가격, 동일가격 처리, 청렴계약, 전자계약 |
| B. 충남 계열 반복관행 | 기본 문구로 제시하고 기관 수정 가능 | 공고정보표, 담당자·입찰집행관 표기, 설계서 열람 안내 |
| C. 개별 특수조건 | 입력 또는 선택 후 삽입 | 차량연식, 노선, 숙소, 강사구성, 점검주기, 작업시간 |

## 3. 확보·검증 우선순위

1. 충남교육청·교육지원청·직속기관·학교의 2025년 이후 공고 원문과 첨부 HWPX/PDF
2. 나라장터 원문 및 첨부파일
3. 국가법령정보센터 법령·시행령·시행규칙
4. 행정안전부 지방계약 예규, 조달청 고시·지침, 중기부·SMPP 기준

각 수집표본에는 아래 메타데이터를 반드시 남긴다.

- 발주기관, 공고일, 계약유형, 추정가격 구간, 계약방법
- 원문 URL 또는 파일 식별값
- 공통문구(A), 충남 계열 반복문구(B), 특수조건(C) 표시
- 법령·예규명, 조문, 기준일, 검증일
- `필수 / 조건부 / 기관 관행 / 선택조건 / 담당자 확인 필요` 상태

## 4. 현재 법령 확인 메모

| 항목 | 현재 처리 | 상태 |
|---|---|---|
| 학교급식 식재료 입찰참가 제한·수의계약 배제 | 학교급식법 제15조의2 및 시행령 제12조의2를 식재료 프로필에 반영 | 조건부·2026-08-20 이후 공고/수의계약 적용 여부 확인 |
| 통학운송서비스 | 세부품명·중소기업제품·직접생산은 SMPP 최신목록 확인으로 남김 | 담당자 확인 필요 |
| 수학여행·방과후 제안서 점수 | 2단계 입찰 검토와 문서세트만 자동화 | 통과점수·배점은 학교 확정 |
| 시설 법정점검 | 법정점검 여부와 자격·법령을 입력받음 | 시설별 개별법령 확인 필요 |
| 청소·방역 | 단순노무 원가·근로보호 항목 자동제시 | 계약 예정연도 임금·보험료율 확인 필요 |

## 5. 다음 표본수집 순서

1. 통학차량 소액수의·경쟁입찰 각 3건 이상
2. 수학여행·현장체험학습 2단계 입찰 3건 이상
3. 교복·급식식재료·우유 각 3건 이상
4. 교실 리모델링·방수·전기·소방 각 2건 이상
5. 법정점검·청소·방역 각 2건 이상
