# 유형별 공고문 공통문구

## 수학여행·현장체험학습

### A. 법령·예규상 공통
- 지방계약법 시행령 제18조에 따른 2단계 규격·가격 입찰 적용 여부
- 규격적격자에 한한 가격개찰
- 입찰보증금·입찰무효·청렴서약·전자입찰 유의사항

### B. 충남 표본에서 반복
- 제안서 직접제출 + 가격입찰 G2B 전자제출
- 예정인원은 증감 가능
- 기초금액 ±3% 범위 복수예비가격 15개 중 4개 평균 방식
- 예정가격 이하 최저가격 낙찰
- 항목별 산출내역 및 실제 인원 정산

### C. 개별 특수조건 또는 학교 선택
- 제안서 적격점수
- 동일가격 처리방식
- 계약체결 기한
- 항공권 예약·승계
- 안전요원 인원·자격
- 숙박시설 등급
- 테마별 분리운영
- 취소·재난·감염병 대응조건

자동생성기는 C 항목을 사실상 표준으로 고정하지 않는다.


## 방과후·늘봄

### A. 법령·예규상 공통
- 지방계약법 시행령 제18조에 따른 2단계 입찰 적용 여부
- 동시입찰 시 규격적격자로 확정된 자에 한하여 가격입찰 개찰
- 입찰무효·보증금·청렴계약 등 공통계약 조항

### B. 충남 표본에서 반복
- 제안서 직접제출 + 가격 G2B 전자제출
- 총액입찰
- 85점 이상 규격적격 기준(충남 표본 기본값 후보, 법정 고정값 아님)
- 규격적격자 가격개찰 후 예정가격 이하 최저가 낙찰
- 동일가격 시 제안서 점수 우선, 재동점 시 추첨
- 충남 지역제한, 공동수급 불허
- 실제 학생수·운영일수·프로그램 변동 시 변경계약·정산
- 프로그램별 강사료와 운영차시를 원가·산출내역과 연결

### C. 조건부·개별 특수조건
- 인건비 반영비율
- 교재·교구·재료비 포함 여부
- 중소기업자간 제한 및 비영리법인 예외
- 최근 수행실적 요건
- 제안서 평가방식·발표시간
- 계약체결 기한
- 전자계약 여부
- 프로그램별 회당 수업시간·주당 횟수·총 차시


## 통학차량·통학버스

### A. 법령·조달기준
- 전세버스운송사업 등록
- 세부품명·중소기업자간 경쟁제품·직접생산 확인
- 어린이통학버스 해당 시 신고·안전장치·교육·동승보호자
- 경쟁입찰 적격심사는 공고일 현재 조달청 일반용역 적격심사 [별표 5] 확인

### B. 충남 표본에서 반복
- 전자견적/전자입찰과 보낸 문서함 확인
- 예정가격 ±3%, 복수예비가격 15개 중 4개 평균
- 지역제한
- 공동수급 불허
- 차량등록증·보험·검사·운전자 자격 확인
- 노선·운행일수·학사일정 변동 가능
- 과업지시서·특수조건·노선표 병행

### C. 학교 선택·계약별 조건
- 총액/단가
- 차량연식
- 직영차량
- 차량대수·정원·노선·요일·일수
- 동일가격 처리
- 적격심사 서류제출기한·계약체결기한
- 최저임금 확약·사회보험료 사후정산

과거 공고의 낙찰하한율은 현재 템플릿의 기본값으로 사용하지 않는다.
