# 유형별 공고문 공통문구

## 수학여행·현장체험학습

### A. 법령·예규상 공통
- 지방계약법 시행령 제18조에 따른 2단계 규격·가격 입찰 적용 여부
- 규격적격자에 한한 가격개찰
- 입찰보증금·입찰무효·청렴서약·전자입찰 유의사항

### B. 충남 표본에서 반복
- 제안서 직접제출 + 가격입찰 G2B 전자제출
- 예정인원은 증감 가능
- 기초금액 ±3% 범위 복수예비가격 15개 중 4개 평균 방식
- 예정가격 이하 최저가격 낙찰
- 항목별 산출내역 및 실제 인원 정산

### C. 개별 특수조건 또는 학교 선택
- 제안서 적격점수
- 동일가격 처리방식
- 계약체결 기한
- 항공권 예약·승계
- 안전요원 인원·자격
- 숙박시설 등급
- 테마별 분리운영
- 취소·재난·감염병 대응조건

자동생성기는 C 항목을 사실상 표준으로 고정하지 않는다.
