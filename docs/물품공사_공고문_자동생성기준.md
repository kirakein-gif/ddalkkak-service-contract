# 물품·공사 공고문 자동생성 기준 (2026-09-26)

## 목적

딸깍 계약업무가 생성하는 물품·공사 HWPX 중 첫 문서를 실제 학교 계약담당자가 공고 전에 검토·수정할 수 있는 수준의 공고문 초안으로 만든다.

자동화는 공고문 작성을 돕는 것이며 최종 게시 전에 계약담당자가 공고일 현재 법령·예규·기관지침과 나라장터 설정값을 확인한다.

## 1. 계약경로에 따른 문서 제목

### 물품
- 추정가격 2천만원 이하 1인 견적 경로: 수의계약 견적요청서
- 2인 이상 견적 수의계약: 소액수의 견적제출 안내공고
- 경쟁입찰: 물품 구매 입찰공고

### 공사
- 추정가격 2천만원 이하 1인 견적 경로: 수의계약 견적요청서
- 2인 이상 견적 수의계약: 수의계약 견적제출 안내공고
- 금액기준 수의계약 범위 초과: 공사 입찰공고

## 2. 물품 공고문 자동항목
- 발주기관 / 공고번호
- 품명·규격·수량
- 예산액·기초금액·추정가격
- 납품기한·납품장소
- 총액/단가계약
- 공동수급 허용 여부
- 견적·입찰 개시 / 마감 / 개찰
- 지역제한
- 나라장터 세부품명·세부품명번호
- 소기업·소상공인 조건
- 중소기업자간 경쟁제품 여부
- 직접생산확인
- 예정가격 작성방법
- 계약상대자 결정방법
- 입찰보증금 또는 수의견적 보증금 면제 문구
- 입찰무효
- 청렴계약
- 이해충돌방지법상 수의계약 제한
- 면세사업자 부가가치세 처리
- 담당자 연락처

### 소액수의 물품의 가격기준
- 추정가격 2천만원 초과 1억원 이하: 일반적으로 88%
- 추정가격 2천만원 이하를 2인 이상 공개견적으로 집행하는 경우: 90%
- 출판문화산업 진흥법 제22조 적용 도서·간행물은 도서정가제 할인제한을 반영하여 90% 기준과 별도 예가범위를 확인

간행물은 일반 물품과 동일하게 기초금액 ±3%를 기계적으로 적용하지 않고 공고일 현재 도서정가제와 기관의 예가 설정방식을 확인한다.

## 3. 공사 공고문 자동항목
- 공사종류(종합 / 전문 / 기타공사)
- 공사현장
- 공사기간
- 요구 업종·주력분야
- 설계서·내역서·시방서 열람
- 현장설명 여부
- A값
- 국민연금보험료
- 국민건강보험료
- 노인장기요양보험료
- 퇴직공제부금비
- 산업안전보건관리비
- 안전관리비
- 품질관리비
- 법정경비 사후정산
- 공사근로자 노무비 구분관리·지급확인
- 하도급 관련 유의사항
- 산업안전·중대재해
- 착공·준공서류
- 하자보증

### 공사 수의계약 금액구간
- 종합공사: 추정가격 4억원 이하
- 전문공사: 추정가격 2억원 이하
- 그 밖의 공사 관련 법령 공사: 추정가격 1억6천만원 이하

### 공사 소액수의 견적률
2인 이상 견적 공사는 89.745% 기준을 사용한다.
비교식은 단순 총액이 아니라 (견적가격 - A값) / (예정가격 - A값) >= 89.745% 형태로 안내한다.
A값은 공고별 실제 계상액을 입력해야 하며 자동 추정하지 않는다.

## 4. 예정가격 문구
일반적인 물품·공사 전자견적 공고는 기초금액 기준 ±3% 범위의 복수예비가격 15개를 작성하고, 참가자가 2개씩 선택한 뒤 다빈도순 4개 가격을 산술평균하여 예정가격을 결정하는 구조를 사용한다.

단, 도서정가제 적용 간행물, 예정가격 작성 예외 계약, 기관 또는 지정정보처리장치에서 별도 범위를 정한 경우는 별도 확인한다.

## 5. 자동으로 확정하지 않는 사항

### 물품
- 세부품명·세부품명번호
- 중소기업자간 경쟁제품 지정 여부
- 직접생산확인 대상 세부품명
- 특정 규격·브랜드 제한의 적정성
- 경쟁입찰의 계약이행능력심사 낙찰하한율
- MAS·제3자단가계약 사용 여부

### 공사
- 정확한 업종·주력분야
- 상호시장 진출 허용 여부
- A값 세부금액
- 지역제한 범위
- 경쟁입찰 적격심사 낙찰하한율
- 공종별 하자담보책임기간
- 산업안전보건관리비 등 계상대상·금액
- 중대재해처벌법상 발주자 확인사항

이 항목들은 입력 필요 또는 검토 필요로 남긴다.
