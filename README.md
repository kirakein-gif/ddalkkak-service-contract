# 딸깍 용역계약

충청남도교육청 등 지방자치단체 소속 기관의 **용역 계약업무를 단계별로 안내·검증·문서화**하기 위한 웹 기반 업무도구입니다.

## 장기 구조

이 프로젝트는 최종적으로 **공사·용역·물품을 모두 포함하는 학교 계약업무 플랫폼**으로 확장합니다.

- 공사(WORKS) / 용역(SERVICE) / 물품(GOODS)이 공통 계약 사건카드를 사용
- 학교 한 곳을 하나의 독립 Organization/Tenant로 관리
- 현황판·나라장터·HWPX·일정·이력은 공통 Core 기능
- 법령 Rule Engine과 문서 템플릿은 계약영역·세부업무별 모듈로 분리
- 상위기관의 하위학교 열람은 자동 상속하지 않고 별도 권한으로 제어

상세 설계: `docs/학교단위_멀티테넌트_계약플랫폼_설계.md`

## 목표

- 계약 조건을 입력하면 적용 가능한 계약 절차와 확인사항을 구조화해 안내
- 지방계약 관련 법령·예규·기관 기준의 적용 근거를 함께 표시
- 나라장터(OpenAPI)에서 공고·개찰·낙찰·계약정보를 조회해 사건카드에 연결
- 계약방법 결정 품의, 공고문, 낙찰·계약 관련 문서 작성을 자동화
- 최종 판단과 승인 권한은 담당 공무원에게 유지

## 1.0 범위

첫 버전은 **용역계약**에 집중합니다.

1. 소액수의·2인 이상 견적제출
2. 일반·제한경쟁 입찰
3. 적격심사 대상 용역
4. 공고 → 개찰 → 낙찰 → 계약체결 흐름

AI 서류검토는 1.0 필수 기능에서 제외하고, 향후 선택 모듈로 추가할 수 있도록 구조만 분리합니다.

## 개발 원칙

- 법적 판단은 가능한 한 **규칙 기반(Rule Engine)** 으로 처리
- AI는 향후 서류 분류·정보 추출 등 보조 역할에 한정
- 자동 생성 결과에는 **근거 규정과 기준일**을 표시
- API 키·인증정보는 저장소에 커밋하지 않음
- 담당자가 최종 확인·승인한 뒤 나라장터에서 실제 등록·계약 처리
